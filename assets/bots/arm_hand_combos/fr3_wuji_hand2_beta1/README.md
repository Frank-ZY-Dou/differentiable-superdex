# FR3 with Wuji Hand 2 (Beta 1)

This directory contains a SuperDex assembly that references:

- Franka FR3 arm: [`../../arms/fr3`](../../arms/fr3) — see its README, LICENSE, and NOTICE.
- Wuji Hand 2 (Beta 1): [`../../hands/wuji_hand2_beta1`](../../hands/wuji_hand2_beta1) — see its README, LICENSE, and NOTICE.

The hand is mounted on the flange (`fr3_link8`) with the fingers along the flange axis; the 3 cm offset clears the wrist housing.
