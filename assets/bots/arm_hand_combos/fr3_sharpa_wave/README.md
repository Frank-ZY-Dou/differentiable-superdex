# FR3 with Sharpa Wave

This directory contains a SuperDex assembly that references:

- Franka FR3 arm: [`../../arms/fr3`](../../arms/fr3) — see its README, LICENSE, and NOTICE.
- Sharpa Wave: [`../../hands/sharpa_wave`](../../hands/sharpa_wave) — see its README, LICENSE, and NOTICE.

The hand is mounted on the flange (`fr3_link8`) with the fingers along the flange axis.
